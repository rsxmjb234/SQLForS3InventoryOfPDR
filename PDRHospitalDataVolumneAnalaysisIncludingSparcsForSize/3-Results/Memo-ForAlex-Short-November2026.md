# Hospital CCDs in PDR vs SFDC, by QE (November 2026)

Alex,

Which SFDC hospitals we can find sending CCDs to PDR. This covers the 194
participating hospitals SPARCS knows. "Submitting" means we found CCDs for the
hospital under any code: the SFDC AA, HEC's new HECDSS codes, Hixny DOC codes, or a
Healthix system code. It's 28 days of data and still early, so treat it as
directional.
